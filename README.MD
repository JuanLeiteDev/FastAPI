# FastAPI com frontend

## Executar o projeto

Com o ambiente virtual ativo, execute:

```powershell
uvicorn app.main:app --reload
```

Depois aceda a [http://127.0.0.1:8000](http://127.0.0.1:8000). A interface permite criar uma conta, iniciar sessão, configurar e confirmar o 2FA, consultar os dados da conta e terminar a sessão.

A documentação interativa da API continua disponível em [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
